================================================================================
EXPERIMENT 2(B) — REST API TESTING USING POSTMAN
================================================================================

Step 1 — Open Terminal & Navigate to Directory
--------------------------------------------------------------------------------
cd Postman


Step 2 — Install Dependencies
--------------------------------------------------------------------------------
npm install

(Installs Express 5 based on package.json)


Step 3 — Run the Server
--------------------------------------------------------------------------------
node server.js
(or: npm start)

Output:
Server Running on Port 5000

Note: Keep this terminal running!


Step 4 — Test Using Postman
--------------------------------------------------------------------------------

Option A: Quick Import (Recommended)
------------------------------------
In Postman, click "Import" button -> select:
Cloud_Lab_Ex2B_Student_API.postman_collection.json

All requests are pre-configured!


Option B: Manual Requests
-------------------------

1. POST Request (Add Student):
   - Method: POST
   - URL: http://localhost:5000/student
   - Headers:
     Content-Type: application/json
   - Body -> raw -> JSON:
     {
       "name": "Loknaath",
       "age": 20,
       "department": "CSE"
     }
   - Click "Send"
   - Expected Output:
     {
       "message": "Student added successfully",
       "data": {
         "name": "Loknaath",
         "age": 20,
         "department": "CSE"
       }
     }

2. GET Request (Get All Students):
   - Method: GET
   - URL: http://localhost:5000/student
   - Click "Send"
   - Expected Output:
     [
       {
         "name": "Loknaath",
         "age": 20,
         "department": "CSE"
       }
     ]

3. PUT Request (Update Student by Name):
   - Method: PUT
   - URL: http://localhost:5000/student/Loknaath
   - Headers:
     Content-Type: application/json
   - Body -> raw -> JSON:
     {
       "age": 21,
       "department": "IT"
     }
   - Click "Send"
   - Expected Output:
     {
       "message": "Student updated successfully",
       "data": {
         "name": "Loknaath",
         "age": 21,
         "department": "IT"
       }
     }

4. DELETE Request (Delete Student by Name):
   - Method: DELETE
   - URL: http://localhost:5000/student/Loknaath
   - Click "Send"
   - Expected Output:
     {
       "message": "Loknaath deleted successfully"
     }

5. Verify (GET All Students):
   - Method: GET
   - URL: http://localhost:5000/student
   - Click "Send"
   - Expected Output:
     []

PART 2 — THIRD-PARTY API INTEGRATION IN POSTMAN
================================================================================

Example: Public Live Weather API (Open-Meteo)

1. Open Postman -> click "+" to create a new tab.
2. Select Method: GET
3. Enter URL:
   https://api.open-meteo.com/v1/forecast
4. Click "Params" tab and add query parameters:
   Key: latitude         | Value: 9.9252
   Key: longitude        | Value: 78.1198
   Key: current_weather  | Value: true

   Final Generated URL:
   https://api.open-meteo.com/v1/forecast?latitude=9.9252&longitude=78.1198&current_weather=true

5. Click "Send"
6. Expected Output (Status 200 OK):
   {
     "latitude": 9.947276,
     "longitude": 78.11024,
     "timezone": "GMT",
     "elevation": 141.0,
     "current_weather": {
       "time": "2026-10-21T05:00",
       "temperature": 25.5,
       "windspeed": 1.3,
       ...
     }
   }
